# Фаза 1 — дизайн-система Android

Объём согласован владельцем: только дизайн-система и галерея компонентов. Фазы 2–7 не начаты; iOS отложен. Ядро upstream и существующие рабочие экраны сохранены. Новый интерфейс — Java/Views, без WebView и HTML.

## Открытие

Настройки приложения → Разработчику → Галерея Glass UI.

Components содержит все типы строк: bool, число с единицей, mm/%, enum в bottom sheet, строка, многострочный шаблон, кнопка, число с переключателем. Представлены loading/empty/error/offline/disabled, карточка, чипы, четыре состояния нижней навигации и режим Reduce transparency. Process и Preferences демонстрируют композицию компонентов. Кнопки Reference preview открывают виды без служебной шапки галереи; стрелка и системное действие «Назад» возвращают в галерею.

Данные локальны Activity, переживают поворот через Bundle, не записываются в настройки upstream, не меняют пресеты, не вызывают сеть или нарезку. Кнопки Browse/Save в галерее показывают демонстрационное действие. Полные рабочие страницы и привязка к схеме опций входят в Фазу 2.

## Структура

| Компонент | Назначение |
|---|---|
| GlassTokens | Неизменяемые значения из assets/design/glass_tokens.json |
| GlassBackground | Три радиальных градиента из токенов |
| GlassSurface | Заливка, обводка, скругление и отдельный слой RenderEffect |
| GlassTypography | Manrope 400/500/600/700 |
| GlassIcon | Официальный Material Symbols Outlined, оптический размер 24, вес 400 |
| GlassUi | Карточки, строки, поля, чипы, кнопки, заголовки |
| GlassSwitch | Визуальный размер 42×24, область касания ≥44×44 dp, роль switch |
| GlassNavigation | Workspace / Settings / Export / Preferences, пилюля 64 dp |
| GlassBottomSheet | Выбор и справка, прокрутка, ограничение доступной высотой окна |
| GlassGalleryActivity | Изолированная галерея и демонстрационные композиции |

## Ограничения и отклонения

- RenderEffect на Android 12+ размывает отдельную копию статического градиента. Произвольное динамическое содержимое и OpenGL под карточкой пока не захватываются. Текст не размывается. На API 26–30 и в Reduce transparency используется заливка.
- PNG не содержат системных панелей Android. В приложении отступы system bars/cutout учитываются отдельно; они уменьшают доступную область и меняют её высоту относительно макета 390×844.
- Референсные композиции — образцы компонентов; полный список опций и все страницы из 35 макетов относятся к следующим фазам. Незавершённые вкладки намеренно показывают короткие примеры.
- Manrope и Material Symbols поставляются локально, без загрузки шрифтов при работе. Лицензии: Manrope-OFL.txt и Material-Symbols-LICENSE.txt.
- Исходные токены v2 дают расчётный контраст около 4,83:1 для основного и 4,55:1 для вторичного текста на одной стеклянной поверхности в светлой точке. Вложенные полупрозрачные элементы могут нарушать 4,5:1. Токены самовольно не менялись; для них требуется согласование либо использование Reduce transparency (#5A5F69).
- Динамический размер шрифта использует sp; подписи и роль switch заданы. Полная проверка TalkBack и его фокуса при перестроении страницы остаётся отдельной задачей доступности. Позиции прокрутки сохраняются, фокус TalkBack пока сбрасывается.

## Сборка и граница проверки

Gradle `:app:assembleDebug` собирает APK. Полный `:app:lintDebug` обнаруживает 10 существовавших ошибок в старых экранах (GestureBackNavigation, NewApi, WrongConstant). Новая галерея этих ошибок не добавляет; проверка не объявляется полностью пройденной.

Отчёт визуальной проверки, фактические скриншоты и сравнение с макетами поставляются рядом с APK отдельно. Пиксельное совпадение и прохождение всех критериев всего ТЗ не следуют из успешной сборки.
