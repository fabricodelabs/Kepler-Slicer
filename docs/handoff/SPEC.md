# ТЗ для Codex: Kepler Slicer для Android (Glass UI)

Все пути относительно папки, где лежит этот файл. Ничего менять в путях не нужно.

## 0. Как работать

1. Прочитай этот файл, `design/index.md` и `design/tokens.json`.
2. Фазы 0–1 завершены. После «Ок» владельца разрешена **Фаза 2** (раздел 11): настройки из схемы. Фазы 3–7 пока не разрешены.
3. К следующей фазе переходи только после моего «ок».
4. Ничего не выдумывай. Нет данных, значит вопрос в отчёт. Скриншоты в `design/png` важнее текста при расхождении.
5. Ядро слайсинга (libslic3r или то, что подключено в порте) не менять без согласования.

Иконки условные: заменить на Android Material Symbols того же стиля.

## 2. Цель

Полноценный слайсер на телефоне: **все** настройки десктопной версии доступны, но поданы в мобильном UI в стиле глазморфизма. UI отделён от ядра слайсинга. Портрет, базовый размер 390×844 dp.

Текущий объём работ — **только Android-приложение Kepler Slicer**. iOS отложен и не входит в текущие фазы или критерии приёмки. Сохраняется существующий нативный Android-стек Java/Views; HTML — источник размеров и цветов макета, а не реализация приложения.

## 3. Дизайн-система

Точные значения в `design/tokens.json`. Кратко:

- Фон: база `#4A4F59` + три радиальных градиента. Стекло: заливка `rgba(255,255,255,.14)`, обводка 1 pt `rgba(255,255,255,.24)`, блюр ≈18, радиус 24 (карточки), 28 (вьюпорт).
- Тёмный акцент `#1C1A18`: активные чипы, главные кнопки, активный пункт навигации.
- Текст белый, вторичный `rgba(255,255,255,.95)`, контраст не ниже 4.5:1 (в макетах v2 уже исправлено: самое светлое пятно фона `#565B65`, расчётный контраст ≈4.8:1; проверить замером на устройстве).
- Шрифт Manrope 400/500/600/700. Заголовок экрана 18/600, карточки 16/700, тело 14, подпись 12.
- Строка настройки: высота ≥44, отступ 16, разделитель `rgba(255,255,255,.12)`. Переключатель 42×24. Чип высотой 28.
- Нижняя навигация: пилюля 64, отступы 20, активный пункт шире, с подписью и белым кругом 40.
- Блюр: Android 12+ RenderEffect для отдельного фонового слоя, без размытия текста и элементов управления; ниже — полупрозрачная заливка без блюра. Размытие фона за 3D-поверхностью проверяется отдельно. При «Reduce transparency» заливка `#5A5F69`. Зона касания ≥44×44 dp.

## 4. Навигация

Нижняя панель: **Workspace · Settings · Export · Preferences**.

- **Workspace:** шапка принтера (тап — выбор принтера и сопла; иконка Wi-Fi — шторка Device: камера, прогресс, температуры, Pause/Stop); правая панель Prepare / Preview / Objects & tools; чип плиты «Plate 1» (мультиплейт, Slice all, Arrange all); «+» (Import Model); карточка объекта; Slice.
- **Settings:** Printer, Filament (слоты, библиотека профилей), Process (Global/Objects, Advanced, вкладки Quality, Strength, Speed, Support, Multimaterial, Others, Notes), внизу Calibration.
- **Export:** G-code (.gcode/.bgcode), .3mf, STL плиты, config bundle, flavor, binary G-code, thumbnails, отправка на принтер.
- **Preferences:** General, Control, Online, Associate, Developer.
- Legacy-экраны переносятся так: Printers и Network → Settings → Printer; Plate controls → Workspace; Sliced preview → режим Preview в Workspace; Filament library / Filament settings / Printer settings → Settings; Device & camera → шторка из Wi-Fi; Calibration → Settings; Multi-plate → чип плиты; App preferences → Preferences.

## 5. Настройки — генерировать из схемы

1. Источник: определения опций ядра (`ConfigOptionDef` / `PrintConfig`) и раскладка страниц и групп из десктопных `Tab` (Print/Process, Filament, Printer). Для опции: ключ, подпись, подсказка, тип, единицы, min/max, enum, режим (Simple/Advanced/Expert), страница, группа.
2. Виджеты: bool → переключатель; число с единицей (`0.2 mm`, `200 mm/s`); «мм или %»; enum → выпадающий список (bottom sheet); строка и многострочный шаблон (filename format); кнопка (`Browse…`, `Test…`, `Clear`, `Reload`); значение + переключатель (`Auto backup` + секунды).
3. Переключатель Advanced — режим видимости. Сегмент Global/Objects — глобально или переопределение для выбранного объекта.
4. Поиск по всем опциям (подпись и ключ), переход к строке с подсветкой. Подсказка опции — ⓘ или долгое нажатие, bottom sheet.
5. Пресеты: system/user, наследование, индикатор несохранённых изменений, Save / Save as / Delete / Reset. Совместимость с десктопом: JSON-бандлы Orca и .3mf с конфигом.
6. Длинные списки (Quality ≈60 строк) виртуализировать. Шапка, вкладки и навигация закреплены, список прокручивается внутри.
7. **Тест покрытия:** скрипт сравнивает опции десктопных Tab с опциями, доступными в мобильном UI, и печатает расхождения. Цель: 0 необъяснённых пропусков.

## 6. Экраны и поведение

- **Workspace:** карточка объекта открывает его свойства. На время нарезки Slice показывает прогресс и отмену. «+» скрыт, пока открыта шторка инструментов.
- **Tools sheet:** сетка 4×3: Move, Rotate, Scale, Place on face, Cut, Support paint, Seam paint, Fuzzy skin, Text, Measure, Boolean (неактивна без двух объектов), Arrange. Выбор открывает нижнюю панель с числовыми полями (позиция, поворот, масштаб с замком пропорций).
- **Import Model:** вкладки STL / 3MF / OBJ (плюс STEP, AMF), источники Files (системный Android Storage Access Framework и установленные облачные файловые провайдеры), системная передача Android, Recent Files, From URL, сетка недавних моделей, Choose file. iCloud Drive и AirDrop на макетах — iOS-примеры, в Android не реализуются. Парсинг вне главного потока.
- **Preview:** слайдер слоёв справа, легенда типов линий (Outer wall, Inner wall, Top surface, Infill, Support, Bridge), режимы окраски (Line type, Speed, Flow, Layer height, Temp), таймлайн ходов, время, расход, стоимость, Send to printer / Export G-code.
- **Network:** тип хоста (Moonraker, OctoPrint, PrusaLink, Duet, Bambu LAN, Repetier), host, port, API key (Android Keystore), проверка сертификата, upload after slicing, Test connection, поиск устройств (mDNS).
- **Preferences:** поля как на `reference/desktop_preferences_*.png`. Mouse-опции заменены на сенсорные: «Zoom to pinch center», «Swap pan and rotate gestures», «Reverse pinch zoom». Вкладка Associate в макете не нарисована: собрать по общему шаблону строк.

## 7. 3D-вьюпорт

- Жесты: 1 палец — орбита, 2 — панорама, щипок — зум, двойной тап — вписать. Видовой куб и виды Iso/Top/Bottom/Front/Back/Left/Right.
- Стол: форма, размер, высота и текстура из профиля принтера, тип плиты, сетка, предупреждение при выходе за область печати.
- Объекты: выбор, множественный выбор, гизмо Move/Rotate/Scale, Place on face, плоскость Cut, кисти Support/Seam/Fuzzy skin, Text, Measure, Boolean, Arrange, Auto-orient.
- Цель: 60 fps на целевом устройстве, нарезка в фоновом потоке, отмена без утечек памяти.

## 8. Адаптация десктоп → мобильный

Мышь → касания; правая кнопка → долгое нажатие; горячие клавиши → меню и жесты; тултипы → ⓘ-шторки; многоколоночные диалоги → один столбец; вкладки → горизонтальные чипы; окно Preferences → экран.

## 9. Состояния и доступность

Для каждого экрана: загрузка, пусто, ошибка, отключено (opacity .5 + disabled), офлайн для сетевых функций. Динамический размер шрифта, подписи TalkBack у всех иконок, роль switch у переключателей, haptic на переключателях и выборе инструмента. Все строки в Android-ресурсы (локализация RU позже).

## 10. Критерии приёмки

1. Каждый экран совпадает со скриншотом: токены из `design/tokens.json`, расхождение отступов ≤4 pt.
2. Тест покрытия настроек: 0 необъяснённых расхождений с десктопом.
3. Пресеты и проекты открываются в десктопном Orca и обратно без потерь.
4. Нарезка и экспорт дают тот же G-code, что десктоп на тех же настройках.
5. Состояния и доступность из раздела 9 есть на всех экранах.

## 11. План работ

- **Фаза 0. Аудит.** Только чтение: стек, структура репозитория, слой слайсинга, формат пресетов, сборка. Отчёт и вопросы. Код не менять.
- **Фаза 1. Дизайн-система.** Токены, компоненты (стеклянная карточка, строки всех типов, чип, переключатель, нижняя навигация, bottom sheet), галерея компонентов, совпадающая со скриншотами.
- **Фаза 2. Настройки из схемы.** Settings, Process (все вкладки), Filament, Printer, Preferences, поиск, пресеты, тест покрытия.
- **Фаза 3. Workspace и вьюпорт.** Шапка, стол, объекты, жесты, инструменты, мультиплейт.
- **Фаза 4. Файлы.** Импорт STL/3MF/OBJ/STEP/AMF, экспорт G-code/.bgcode/.3mf/STL/config bundle.
- **Фаза 5. Нарезка и Preview.** Фоновая нарезка, слои, легенда, таймлайн.
- **Фаза 6. Сеть и Device.** Хосты, обнаружение, upload/print, камера, прогресс.
- **Фаза 7. Калибровки, полировка, доступность.**

Правила для каждой фазы: небольшие коммиты; скриншот каждого экрана рядом с макетом; список отклонений от дизайна с причиной; без «ок» от меня в следующую фазу не переходить.

## 12. Вопросы, на которые ответит владелец

Платформа согласована: Android, Java/Views; iOS отложен. Подключённое ядро определено аудитом: OrcaSlicer libslic3r через JNI. Открытые вопросы: целевой Android-телефон и минимальная версия ОС; эталонная версия десктопной Orca и критерий сравнения G-code; функциональные цвета Preview и отдельная светлая тема. Требование перенести все протоколы Orca сохраняется. Перед реализацией конкретной следующей фазы вопросы уточняются без сокращения согласованного объёма.
