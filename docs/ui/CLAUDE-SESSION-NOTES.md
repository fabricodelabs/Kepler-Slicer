## Context and decisions

- Owner (chat, 2026-11-04) asked for a 1:1 port of Figma "Kepler Slicer — Glass UI v3"
  (`OBNMhh3YDB0kRzvPnSERYW`, page `0:1`) and explicitly **lifted the ownership limits** of AGENTS.md/CLAUDE.md:
  Claude may edit any UI file, build, install and test on the emulator, and commit/push `claude/ui`.
  Engine/JNI/stores/protocol logic stay untouched. The edited paths are appended to the Claude list in
  `docs/collaboration/ownership.json` under `ownerTransfers` UI-010 so the pre-commit scope check passes.
- Owner chose "draw everything": features without a backend are shown as designed and explain on tap
  that they are not connected (never fake data). Printer job control (pause/stop/start) stays disabled.
- v3 is a single dark theme; `MdUi.themeDark` always returns true.

## Where things are

- Icons: `res/drawable/kv3_*.xml`, generated by `tools/SvgToVector.java` from the Library SVGs captured in
  `../Kepler-Figma-v3/<Screen>/assets/` (outside the repo). Command:
  `java tools/SvgToVector.java app/src/main/res/drawable kv3_name=path.svg ...` (JBR java).
- Primitives: `glass/KeplerUi` (chips, glass buttons, header, mode toolbar, object card, tool tiles, axis fields,
  segmented, pill, list rows, switch art), `KeplerScreen` (sub-screen shell + nav), `MdUi` (legacy screens in v3),
  `glass/LayerRail`, `glass/FlowRow`, `glass/GlassSwitch` (Figma Switch), `GlassUi.chip/select/action`.
- Strings: `res/values{,-en,-ru}/kepler_v3_strings.xml` (+ `kepler_v3_plurals.xml`). Keep all three in sync.
- Workspace/Tools/Preview: `MainActivity` (`workspace()`, `buildToolsSheet`, `buildPreviewSheet`, `syncPanels`,
  `setColorMode`). GL: `StlView` (glow backdrop texture, Figma model colours, colour shader for toolpaths, move gizmo).
  Toolpath colours: `GcodeAnalysis` per-segment type/feed/flow/temp + `ToolpathGeometry.colors`.
- Other screens: `ImportActivity` (URL import, `PrimitiveShapes`), `PrinterPickerActivity` (Printers landing +
  library), `ProfilePickerActivity` (Filament/Process library, favourites in prefs `kepler_v3_ui`, alphabet index),
  `GcodeExportActivity` (share via `ShareProvider`, STL/OBJ export), `DeviceActivity` (read-only status),
  `NetworkActivity` (host chips), `SettingsActivity` editor header (`v3EditorHeader`), `PreferencesActivity`.

## Build, run, verify

- Build: `export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"; ./gradlew --offline assembleDebug -q`.
- Emulator `Medium_Phone_API_37.0` (emulator-5554). Install `app/build/outputs/apk/debug/app-debug.apk`;
  launch `com.orcamobile.app/.LaunchActivity` (use `MSYS_NO_PATHCONV=1` in Git Bash). Most activities are not
  exported — navigate through the UI. The STEP sample model takes ~30–40 s to load after launch; taps on the
  workspace are ignored meanwhile. 1 screenshot px = 1.2 × displayed px.
- Commit hook needs pwsh: `export PATH="/c/Users/tails/AppData/Local/Microsoft/WindowsApps:$PATH"`.
- Figma MCP is flaky ("connection lost"); retry, or request child nodes when a frame is too large.
