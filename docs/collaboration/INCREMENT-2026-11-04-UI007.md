# Phase 2 UI-007 — Figma v3 bottom navigation

The Android increment is integrated at `180e64b`. It covers the shared
bottom navigation in Settings, Preferences and the developer gallery.
[Kepler Glass UI v3](https://www.figma.com/design/OBNMhh3YDB0kRzvPnSERYW)

The four pairs of original Figma SVGs and the hashes of their whole-image
Android renders are recorded in the [asset manifest](../ui/figma-v3/nav/manifest.json).
The baseline uses four equal slots, 22dp icons above Manrope captions, a
white selected pill and a 358×68dp bar at 390dp of usable width. Codex
adapted the overlay in the Figma preview to a measured Android footer.
The background uses the existing app treatment and the bar has no live
backdrop blur. The active pill and the footer adapt to font metrics.

Claude Code authored `f0cffa1` with Sonnet and medium reasoning under the
configured USD 1.00 budget and 12 agentic-turn cap. The CLI estimated
USD 0.2409896. Codex corrected the rounded height, caption metrics and
gallery footer in `34195b9`. See the [handoff](../ui/UI-007-HANDOFF.md).

  action, clearing restored the list, and dismissing the IME restored the
  footer to the bottom. Android system Settings temporarily stopped
  responding while applying the scale. The enlarged setting took effect.
  [Portrait capture with keyboard](screenshots/UI-007/settings-large-font-ime.png)
- Existing printer, filament and process selections were visible in
  Settings. The slicing library has the same SHA-256
