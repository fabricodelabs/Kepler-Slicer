# UI-008 — Settings hub on Android

The wired Settings hub is accepted as a Phase 2 increment and integrated at
`aa38e26`. The APK uses application code from `187592e`. Claude Code wrote
the native presentation, live bindings and visual corrections. Codex reviewed
the diff, built the APK, tested it through Computer Use and integrated it.
[Settings frame 6:368](https://www.figma.com/design/OBNMhh3YDB0kRzvPnSERYW?node-id=6-368)

## Implementation and review

The hub uses the original Figma glow layers, Manrope, printer and category
icons, dark picker fields, mint Advanced switch, and the shared navigation.
The live printer, nozzle, filament and process fields use the existing
profile worker. The header search opens the IME and keeps the existing
search matching, no-results and clear actions. Calibration and profile
transfer have separate rows in the final card. The profile inventory
remains available from the menu while search is visible.

After checkpoint `e68d8e9`, one capped run prepared the header (`0bb0d1c`).
A narrower assignment completed the screen binding (`f5a2412`). A targeted
correction added the original printer sliders, localized Advanced, added
the direct transfer row and opened the IME from search (`d5d2166`). Its first
attempt had an incomplete target path and ended without editing. Codex
supplied the exact file path for the correction. Emulator review then found
the scope selection capsule was too short. Claude moved the 32dp minimum
after the single-line configuration (`187592e`).

Claude used Sonnet and medium reasoning. The post-checkpoint CLI estimates
were USD 0.306885 for UI-008B, USD 0.2994653 for binding, USD 0.0320965 and
USD 0.0822969 for the action corrections, and USD 0.0606493 for the capsule
fix. Estimates for the binding and correction runs total USD 0.474508.

## Remaining fidelity work

The Android footer reserves layout space and uses translucent fill without
the Figma overlay's live blur. Live profile data differs from the design's
sample text, swatch, second filament slot and change counters. The hub
uses one real slot and retains its existing material settings action.
The editors, workspace and other Figma screens are outside this increment.
English at the exact Figma frame size and TalkBack remain unverified.
