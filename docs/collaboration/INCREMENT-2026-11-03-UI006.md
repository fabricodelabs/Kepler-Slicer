## Technical behavior and checks

`NativeConfigValues` uses the existing `resolvedSettingsSnapshot` for all three
preset sections. The decoder validates strict UTF-8/JSON and the current fixed
`{options,preset_values}` shape, native types/nullability, schema compatibility,
finite/range constraints and wire echoes. Exact direct numeric values are
converted to the editor's existing upstream string/string-array representation;
rounded serialized numbers are not substituted for those direct values.

Only an absent older JNI symbol permits the explicitly labelled legacy fallback.
Malformed available responses fail explicitly. Profiles, overrides and model
selection are checked before and after native work. The empty-workspace token
is returned only for validated empty state; corrupt or orphaned metadata remains
an error. Full-project Settings remains on its separate read-only path, with
post-call freshness validation. Editable project drafts, scope mapping and export
are not implemented by this increment.
