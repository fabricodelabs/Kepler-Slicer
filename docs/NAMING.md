# Project naming

Kepler Slicer is the product name everywhere: UI text, applicationId and Java package (`com.keplerslicer.app`; fixed for Google Play, never change it), classes, assets
(`kepler_*.json`, `kepler_profiles.zip`), stored preference names and docs. The slicing engine is built from the
pinned upstream source (see README and `LICENSE-ORCASLICER.txt`); prose calls it "upstream" or "the engine".

## Old names that intentionally remain

| What | Why |
| --- | --- |
| `LICENSE-ORCASLICER.txt`, upstream links in README/docs (`github.com/OrcaSlicer/OrcaSlicer`) | AGPL attribution and source provenance are required. |
| `auth.orcaslicer.com`, `api.orcaslicer.com`, GitHub release API URLs | Real service endpoints. |
| `simplyprintorcaslicer`, `"OrcaSlicer"` values in 3DPrinterOS / UltiMaker / Obico requests | Registered client ids and protocol values the services expect. |
| Vendor `OrcaFilamentLibrary` in profile data and slicing code | Engine vendor key; the UI shows it as "Kepler Filament Library" (`EngineText`). |
| Text inside `libkepler_slicer_experimental.so` and its C++ string literals | Changing them needs a native rebuild; the UI rewrites them on display (`EngineText.clean`). |
| `engine/android-headless.patch`, `ORCA_ANDROID_ENGINE_ONLY`, `PresetBundle::ORCA_FILAMENT_LIBRARY`, upstream file names (`OrcaSlicer_ru.po`, `OrcaBadge.3mf`, `src/OrcaSlicer.cpp`) | They apply to, or name things in, the upstream source tree. |
| `; generated by OrcaSlicer` handling in `LegacyHostFiles` | Matches the header the engine writes into G-code. |
| Local folders `outputs/OrcaMobile`, `work/orca-headless-fresh` | Existing paths on the build machine. |
