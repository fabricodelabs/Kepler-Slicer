# Kepler Slicer — Фаза 1, Android

Дата: 2026-11-01. Реализованы дизайн-система и отдельная галерея компонентов. Фаза 2 не начата. iOS исключён из текущего объёма в SPEC.md на рабочем столе и копии ТЗ в проекте.

## Что добавлено

Нативные Java/Views: токены из JSON v2, градиент, стеклянные поверхности с отдельным RenderEffect, Manrope 400/500/600/700, официальный Material Symbols Outlined, карточка, чип, переключатель, четыре пункта pill navigation и bottom sheets. Типы строк: bool, число с единицей, mm/%, enum, текст, многострочный шаблон, кнопка, число с переключателем. Показаны loading/empty/error/offline/disabled.

Галерея: Настройки приложения → Разработчику → Галерея Glass UI. Из Components можно открыть Reference preview: Process/Preferences. Значения существуют только в Activity и Bundle и не меняют настройки слайсинга, профили или сетевые подключения. Остальные вкладки демонстрируют компоненты сокращённо.

Первый запуск самого эмулятора завершился сбоем до установки; владелец завершил зависший процесс, после чего установка состоялась. Это был сбой среды, а не открытой галереи.

## Дизайн: что ещё требует приёмки

1. Область касания чипов и кнопок ≥44 dp больше визуальных чипов макета 28 dp. Ряды вкладок занимают больше вертикального пространства. Отступы шапки/карточки/навигации заданы из макета, но глобальное совпадение ≤4 dp не подтверждено. PNG эмулятора имеет другие пропорции и системные панели; его нельзя выдавать за проверку точно 390×844 dp.
2. Размытие захватывает статический градиент. Динамический вьюпорт и реальное стекло над ним проверяются в Фазе 3. На старых API и в Reduce transparency — fallback.
3. Формат иконок намеренно заменён на Material Symbols по ТЗ; форма отдельных символов отличается от условных SVG.
4. В локальном PNG Preferences в точке (400,640) фон строки RGB(105,109,118), контраст с белым 5.186:1; в точке (800,1210) фона Browse RGB(106,110,115), 5.134:1. Это выборочные замеры, не аудит всех пикселей. Вложенный неактивный пункт навигации (200,2190) RGB(145,148,153), белая иконка около 3.044:1. Согласованные токены не менялись. В исходных макетах более глубокое вложение стекла может снижать текстовый контраст ниже 4.5:1; это следует разрешить до массового переноса рабочих страниц.
5. Полный состав Process/Preferences и связь с ядром входят в Фазу 2. Здесь только композиции компонентов. Нарезка и сеть этой фазой не тестировались и не изменялись.

Рядом: index.html показывает макеты и фактические снимки. К следующей фазе переход только после «ок» владельца.
