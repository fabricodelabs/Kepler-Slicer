## Additional builders and scopes

- TabPrintModel::build (3771–3797) calls the process builder and filters by object capability; four explicit frequent options are present in the preset inventory. Presence there does not implement object overrides.
- TabPrintPlate::build (4109–4132) explicitly adds curr_bed_type, skirt_start_angle, print_sequence, spiral_mode, first_layer_sequence_choice, other_layers_sequence_choice. The first, fifth and sixth are not in the process preset inventory. They belong to project/plate scope and must not silently become process-preset options.
- TabSLAPrint::build and TabSLAMaterial::build contain no active calls from the scanned APIs in this pinned file (much source is commented out). SLA runtime and other helper paths have not been established as implemented by the Android app.
- extruders_count constructs a local desktop Option (6029–6037), controls dynamic extruder pages and is not a normal stored key. Android indexed/nozzle behavior still needs its own proof.
